# iPhone Photo Convert

## ▶ [変換ツールを開く](https://kanzennirikaisita.github.io/iPhone-Photo-Converter/index.html)

**GitHub Pagesを有効にすると、上のリンクから写真を選んで変換できます。ダウンロードやインストールは不要です。**

公開設定：Settings → Pages → Deploy from a branch → main / (root)。Pagesを利用できるプラン・リポジトリの公開範囲で設定してください。

HEIC / HEIFをJPEG / PNGに変換する、Edge / Chrome用ツールです。

ページを開いて写真を選ぶだけで変換できます。ページの初回読み込みにはネット接続が必要ですが、写真は端末内で処理し、サーバーへ送信しません。
完全オフラインで使う場合は、下記の方法でHTMLをダウンロードしてください。

※ GitHubのファイル一覧にある `index.html` を押すと、プログラムの内容が表示されます。ツールを使うときは、上の「変換ツールを開く」を押してください。

## オフラインでの使い方

1. リポジトリをZIPでダウンロードし、展開します。
2. `index.html`をEdgeまたはChromeで開きます。
3. 写真を選択し、「変換する」を押します。
4. 個別に保存、またはZIPでまとめて保存します。

HTML一つで動作します。インターネット接続、管理者権限、HEIF拡張機能、ローカルサーバーは不要です。

## JPEGとPNGの選び方

- JPEG：容量が小さく、写真の共有・保存におすすめ。
- PNG：容量は大きめ。保存時の圧縮による画質劣化を避けたいとき。

迷ったらJPEGでOKです。PNGにしても元の写真より鮮明になるわけではありません。
縦横のピクセル数は維持します。

## 処理の仕組み

同梱のlibheif-jsがHEICの圧縮データをピクセルに展開し、ブラウザーがJPEG / PNGとして保存します。
画像はPC内で処理します。外部送信・広告・分析機能はありません。

## 制限

- EXIF・撮影日時・GPSを引き継ぎません。
- HDR・広色域・高ビット深度は保持しません。
- 複数画像入りのファイルは主画像1枚を出力します。
- Live Photosの動画部分は対象外です。
- 1ファイル100 MB、6500万画素まで。大量の写真は分けて処理してください。
- すべてのHEIF圧縮方式への対応は保証しません。
