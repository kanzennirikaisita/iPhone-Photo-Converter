# iPhone Photo Converter

HEIC / HEIFの写真をJPEG / PNGに変換するツールです。WindowsのEdge / Chromeで使えます。

## ▶ [変換ツールを開く](https://kanzennirikaisita.github.io/iPhone-Photo-Converter/index.html)

インストール不要。写真は端末内で処理し、サーバーへ送信しません。

## 使い方

1. 上のリンクを開き、「写真を選択」でHEIC / HEIFを追加します。
2. JPEGまたはPNGを選び、「変換する」を押します。
3. 各写真の「保存」、または「まとめてZIP保存」で保存します。

複数枚をまとめて変換できます。元の写真は変更しません。

## 完全オフラインで使う

1. このリポジトリの **Code → Download ZIP** でダウンロードし、展開します。
2. 展開した `index.html` をEdge / Chromeで開きます。

`index.html` 一つで動作します。保存後はネット接続もインストールも不要です。

## JPEGとPNGの選び方

- **JPEG**：容量が小さく、写真の共有・保存におすすめ。
- **PNG**：容量は大きめ。保存時の圧縮による画質劣化を避けたいとき。

迷ったらJPEGでOKです。PNGにしても元の写真より鮮明にはなりません。縦横のピクセル数は維持します。

## 注意点

- 撮影日時・GPS・EXIFは引き継ぎません。
- HDR・広色域・高ビット深度は保持しません。色の見え方が変わる場合があります。
- 複数画像を含むファイルは主画像1枚を変換します。Live Photosの動画は対象外です。
- 1ファイル100 MB・6500万画素まで。大量の写真は分けて処理してください。
- すべてのHEIF圧縮方式への対応は保証しません。

同梱エンジンの安全性に関する注意は [SECURITY.md](SECURITY.md) を確認してください。
